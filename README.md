# Portafolio Personal / Personal Portfolio

## Español

### Tecnologías utilizadas

- **React + TypeScript + Vite**

### Características

- Diseño responsivo y animado.
- Secciones hechas con formato modular para una mejor organización y facilidad de edición.

### Descripción

He optado por usar estas tecnologías por considerarlas óptimas a la hora de diseñar y personalizar un sitio web de este estilo, para un diseño limpio, animado y responsivo.
